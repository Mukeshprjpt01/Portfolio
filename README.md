# Mukesh Kumar — Portfolio

A clean, single-file developer portfolio built with pure **HTML5 + CSS3** (no frameworks, no build step). It showcases my work as a **MERN Stack Developer & SDE**, covering real-time systems, backend architecture, DSA fundamentals, tooling, projects, and experience.

## 🌐 Live Demo

> After pushing, enable **GitHub Pages** in the repo under *Settings → Pages*,and the site will be available at:
>
> `https://Mukeshprjpt01.github.io/portfolio/`
>
> (or `https://Mukeshprjpt01.github.io/` if the repo is named `Mukeshprjpt01.github.io`)

## ✨ Features

- Fully responsive single-page portfolio
- Sections: Hero · About · What I Build · Metrics · Toolkit · Projects · Philosophy · Chronology · Contact
- Self-contained — images are embedded as base64, no external assets needed
- Smooth-scroll navigation, sticky navbar, lightweight CSS animations
- Dark footer with back-to-top, social links, direct contact card

## 🚀 Run Locally

Since it's a single static file, just open it in a browser:

```bash

# option 2 — serve it using a local server
npx serve .
```

No dependencies, no build, no install required.
